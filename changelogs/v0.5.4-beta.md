# v0.5.4-beta (2026-01-01)

## What's Changed

### ⚠️ 不兼容变更
- **属性重命名**：`HusDivider` 的 `style` 改名为 `lineStyle`
- **属性移除**：`HusRate` 移除 `isDone` 属性

### 📌 迁移提示
- 全局搜索 `HusDivider.style` 替换为 `HusDivider.lineStyle`，并移除对 `HusRate.isDone` 的使用。

### ✨ 新功能
- **新增组件**：`HusDateTimePickerPanel`（非弹出式日期时间选择面板），由 `HusDateTimePicker` 拆分而来
- **新增主题**：`HusTheme` 新增 `HusRadioBlock` 主题对象（从 `HusRadio` 拆分）
- **新增属性**：`HusTreeView` 新增 `radiusSwitcherBg`、`radiusTitleBg`
  - `HusTableView` / `HusTreeView` 新增 `reuseItems`
- **新增 API**：`HusTheme` 主题表达式新增 `brightness()` 亮度函数
- **方法增强**：`HusBreadcrumb` 的 `get()`、`append()`、`initObject()`、`set()`、`setProperty()`、`insert()`、`remove()`、`move()` 添加参数类型标注
- **组件增强**：`HusDateTimePicker` 重构为基于 `HusDateTimePickerPanel`，原有属性通过别名保持兼容
  - `HusDivider` / `HusTreeView` 的 `lineWidth` 类型由 `int` 调整为 `real`
  - `HusCheckBox` 优化选中动画逻辑，创建后自动启用动画
  - 统一各组件 `colorBorder` / `colorSplit` 主题颜色
  - `HusInputNumber` 优化值更新时机
  - `HusCaptionButton` 优化样式与效果，`HusMultiSelect` 调整 suffix 右边距

### 🐛 Bug 修复
- **行为修复**：`HusCaptionBar` 修复最大化/还原按钮未居中 (#47) 及 `showMaximizeButton` 未生效
  - `HusAutoComplete` / `HusColorPicker` / `HusMultiSelect` / `HusSelect` 修复弹窗先下探再上弹
  - Gallery 未 install 时将生成目录加入导入路径 (#48)
- **动画修复**：`HusSelect` 修复 loading 旋转状态不正确

### 📝 文档
- **文档与示例**：新增 `HusDateTimePickerPanel` 示例
  - 新增 `HusApi` 用法文档与示例
  - 更新 HuskarUI 品牌图标与 README 预览图，修正多处文档描述错误

### 🔧 构建与工具
- **构建改进**：Qt 6.10+ 构建无需链接 `LabsQmlModelsPrivate`
  - macOS CI 工作流更新为 Qt `6.10.1`

### ♻️ 其他改进
- **其他改进**：所有组件统一继承原生 `Control`，并规范代码结构与格式
  - 新增 HuskarUI 品牌图标资源（圆形/方形多尺寸）
  - Gallery 调整控件尺寸与内置 API 信息展示

### **Full Changelog**: https://github.com/mengps/HuskarUI/compare/v0.5.3-beta...v0.5.4-beta
