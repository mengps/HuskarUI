# 0.4.8.3-beta (2025-10-20)

## What's Changed

### ⚠️ 不兼容变更
- **方法重命名**：`HusWindow` 的 `setMacSystemButtonsVisble` 修正拼写为 `setMacSystemButtonsVisible`

### ✨ 新功能
- **新增组件**：`HusEmpty`（空状态），支持图片、描述文字与自定义委托
- **新增主题**：`HusTheme` 新增 `HusEmpty` 主题对象
- **新增属性**：`HusModal` 新增 `closable` (#33)
  - `HusTourStep` 新增 `closable` (#34)
  - `HusCaptionBar` 新增 `winPresetButtonsDelegate`、`topButtonChecked` (#37)
  - `HusInputNumber` 新增 `initBeforeLabelIndex`、`initAfterLabelIndex`
  - `HusCheckBox` 新增指示器圆角 `radiusIndicator`
- **组件增强**：`HusCheckBox` 指示器由直角改为圆角 (#36)
  - 图片相关属性由 `url` 类型统一为 `string`（`HusAvatar` / `HusCard` / `HusImage` / `HusImagePreview` / `HusCaptionBar` 等）
  - `HusTabView` 优化添加按钮与标签交互
  - `HusWatermark` 使用主题初始化的字体与大小
  - `HusTheme.installIndexTheme()` 传入空路径时重置为默认主题，创建时即加载默认主题

### 🐛 Bug 修复
- **行为修复**：修复 `HusTheme.installThemeColor()` 对 `TextBase` / `BgBase` 无效
  - 修复 `HusTableView` 最小高度不生效
  - 修复 `HusCaptionBar` 全屏状态下最大化按钮无法恢复、禁用标题栏时颜色异常
  - 修复 `HusDrawer` 默认间隔导致的白边
  - 修复 `HusPagination` 输入框不应可清除
  - 修复 `ThemeToken` 表格高度不正确

### 📝 文档
- **文档与示例**：README 优化构建说明
  - 新增 `ExpEmpty` 示例，并更新 `ExpModal`、`ExpTourStep`、`ExpCheckBox`、`ExpCaptionBar`、`ExpTabView` 等示例

### ♻️ 其他改进
- **其他改进**：优化 C++ 打印分类，删除 `HusWindowAgent` 冗余代码

### **Full Changelog**: https://github.com/mengps/HuskarUI/compare/v0.4.8.2-beta...0.4.8.3-beta
