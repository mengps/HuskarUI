# v0.1.7-alpha (2025-03-04)

## What's Changed

### ⚠️ 不兼容变更
- 无（首个发布版本）。

### ✨ 新功能
- **新增组件**：初始版本提供 27 个 QML 组件，另含 `DelRectangle`、`DelWatermark`、`DelAsyncHasher`、`DelIconFont` 等 C++ 暴露类型
  - 通用：`DelButton`（按钮）、`DelIconButton`（图标按钮）、`DelIconText`（图标文本）、`DelCopyableText`（可复制文本）、`DelDivider`（分割线）
  - 布局与窗口：`DelCaptionBar`（标题栏）、`DelCaptionButton`（标题按钮）、`DelWindow`（基于 QWindowKit 的无边框窗口）、`DelAcrylic`（亚克力效果）
  - 数据录入：`DelCheckBox`（多选框）、`DelInput`（输入框）、`DelOTPInput`（一次性口令输入框）、`DelRadio`（单选框）、`DelRadioBlock`（成块单选框）、`DelRate`（评分）、`DelSelect`（下拉选择器）、`DelSlider`（滑动条）、`DelSwitch`（开关）、`DelTimePicker`（时间选择框）
  - 数据展示：`DelScrollBar`（滚动条）、`DelTabView`（标签页）、`DelToolTip`（工具提示）、`DelTourFocus` / `DelTourStep`（漫游引导）、`DelWatermark`（水印）
  - 导航与交互：`DelMenu`（菜单）、`DelMoveMouseArea` / `DelResizeMouseArea`（窗口移动与缩放手势区域）
- **新增主题**：引入主题系统：`DelTheme` 单例 + `DelThemeFunctions` 工具方法，支持浅色/深色模式自动切换
  - 内置 18 个组件主题（`DelButton`、`DelSelect`、`DelInput`、`DelRate`、`DelTabView` 等），并提供 `DelColorGenerator`、`DelSizeGenerator` 主题生成器
- **新增 API**：`DelApp` 作为应用初始化入口，统一管理字体、图标字体与全局配置
  - `DelApi` 提供库版本、读取文件为文本等实用接口
  - `DelWindowAgent` 封装基于 QWindowKit 的无边框窗口代理能力
  - 新增 `DelIconFont`（图标字体）与内置图标资源
- **组件增强**：`DelWindow` 支持设置标题栏明/暗模式（`setCaptionMode()`）
  - `DelMenu` 支持初始选中菜单项与模型操作接口
  - `DelRate` 支持自定义星星上方文字提示代理
  - `DelDivider` 支持垂直分割线；图标按钮支持「图标 + 文本」组合并可调整位置

### 🐛 Bug 修复
- **行为修复**：修复暗黑模式下调色板未正确翻转、组件主题路径加载错误的问题
  - 修复初始状态边框颜色、颜色哈希计算等早期问题

### 📝 文档
- **文档与示例**：为全部组件提供 Gallery 示例与文档，示例文档包含「何时使用」「完整描述」等章节

### 🔧 构建与工具
- **构建改进**：新增 Windows 与 Linux 的 GitHub Actions CI 构建工作流
  - 集成 `QWindowKit` 三方库，使用开源图标字体并内置字体/图标资源
  - CMake 构建系统与安装配置初步成型，提供 `UpdateLists.json` 更新列表
- **开发工具**：Gallery 提供首页、设置页、关于页，并实现可编辑/直接运行的示例代码运行器与代码盒子

### ♻️ 其他改进
- **其他改进**：项目采用 MIT 许可证，补充中英文 README 与图标资源
