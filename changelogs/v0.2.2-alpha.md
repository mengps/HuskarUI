# v0.2.2-alpha (2025-03-15)

## What's Changed

### ⚠️ 不兼容变更
- **主题接口重命名**：`DelTheme.reloadDefaultTheme()` 改名为 `reloadTheme()`
  - `DelTheme.registerComponentCustomTheme()` 改名为 `registerCustomComponentTheme()`
- **主题接口移除**：移除 `DelTheme.installIndexThemeJSON()`、`installComponentThemeJSON()`，JSON 字符串安装改为主题文件路径接口 `installIndexTheme()` / `installComponentTheme()`
- **枚举变更**：`DelTheme.DarkMode` 枚举顺序调整为 `Light`、`Dark`、`System`（数值 `0`、`1`、`2`），`darkMode` 属性类型改为该枚举

### 📌 迁移提示
- 将 `reloadDefaultTheme()` 替换为 `reloadTheme()`；使用 JSON 字符串安装主题的代码改用主题文件路径接口。

### ✨ 新功能
- **新增方法**：`DelThemeFunctions` 新增 `genFontFamily()`，用于按基础字体家族生成字体列表
- **组件增强**：`DelTheme` 完善主题接口与属性，统一主题安装、主色与字体配置
  - `DelPagination` 优化页面跳转逻辑
  - `DelDrawer`、`DelSelect` 优化鼠标光标与尺寸
  - 暗色主题颜色映射中的浮点数统一为整数
  - `DelWindow` 改用 `setWindowMode()` 处理暗色模式

### 🐛 Bug 修复
- **行为修复**：修复 `DelCollapse` 边框宽度与矩形宽度计算
  - 更新主题颜色与色彩方案的处理逻辑

### 📝 文档
- **文档与示例**：Gallery 设置页新增主题选择功能
  - 更新 `DelPagination` 文档中支持函数的说明

### 🔧 构建与工具
- **构建改进**：Windows 工作流优化 `windeployqt` 命令，减少不必要的组件与文件
  - 更新 `QWindowKit` 依赖
  - `CMake` 优化部署参数

### ♻️ 其他改进
- **其他改进**：优化代码格式与主题颜色生成逻辑
