# v0.3.2-alpha (2025-05-19)

## What's Changed

### ⚠️ 不兼容变更
- 未发现不兼容变更。

### ✨ 新功能
- **新增组件**：`DelSwitchEffect`（切换特效），内置淡入、模糊、遮罩、百叶窗、3D 翻转、雷电等切换效果
- **新增属性**：`DelSwitchEffect` 新增 `type`、`duration`、`easing`、`maskSource`、`maskScale`、`maskRotation`、`maskColorization` 等属性及 `startCallback`、`endCallback` 回调
- **新增方法**：`DelSwitchEffect` 新增 `startSwitch(from, to)`
- **新增信号**：`DelSwitchEffect` 新增 `started()`、`finished()` 信号
- **组件增强**：`DelMenu` 优化菜单背景颜色与显示逻辑
  - 调整明暗模式背景基色
  - Gallery 切换逻辑与设置页面重构，设置页不再使用弹窗

### 🐛 Bug 修复
- **行为修复**：`DelWindow` 修复重设回 `None` 时未恢复背景色，以及 macOS 下未处理 `None` 的问题
  - 修复设置页未跟随暗黑模式更新的问题

### 📝 文档
- **文档与示例**：新增 `DelSwitchEffect` 示例与文档
  - 修正 `ExpButton` 文档换行错误

### ♻️ 其他改进
- **其他改进**：`CodeRunner` 不再使用亚克力材质

### **Full Changelog**: https://github.com/mengps/HuskarUI/compare/v0.3.1-alpha...v0.3.2-alpha
