# v0.4.9.0-beta (2025-10-27)

## What's Changed

### ⚠️ 不兼容变更
- **属性类型变更**：各组件的圆角属性由 `int` 改为 `HusRadius` 对象，需改用 `HusRadius { all: ... }` 赋值；涉及 `HusButton`、`HusButtonBlock`、`HusInput`、`HusInputNumber`、`HusSelect`、`HusMultiSelect`、`HusCheckBox`、`HusRadio`、`HusRadioBlock`、`HusSwitch`、`HusSlider`、`HusCollapse`、`HusMessage`、`HusNotification`、`HusPopup`、`HusToolTip`、`HusTourStep`、`HusTextArea`、`HusAvatar`、`HusAcrylic`、`HusBreadcrumb`、`HusDateTimePicker`、`HusOTPInput` 等
- **属性重命名**：`HusMenu` 的 `radiusBg` 改名为 `radiusMenuBg`（类型同时改为 `HusRadius`）

### 📌 迁移提示
- 将 `radiusBg: 8` 之类的写法替换为 `radiusBg: HusRadius { all: 8 }`，分角圆角可使用 `topLeft` / `topRight` / `bottomLeft` / `bottomRight`。

### ✨ 新功能
- **新增属性**：新增圆角类型 `HusRadius`，支持 `all`、`topLeft`、`topRight`、`bottomLeft`、`bottomRight`
  - `HusButton`、`HusInput` 新增 `sizeHint` / `sizeRatio` 尺寸提示属性
  - `HusMenu` 新增 `radiusPopupBg`
  - `HusRectangle` 新增 `gradient` 渐变属性
- **新增 API**：`HusTheme` 新增 `sizeHint` 属性与 `installSizeHintRatio()` 方法
- **组件增强**：引入 `sizeHint` / `sizeRatio` 并据此重构组件尺寸计算，统一图标尺寸、间距与内边距
  - 优化 `HusRectangle` / `HusWatermark` 抗锯齿的启用时机
  - `HusCard` 补充遗漏的判断条件

### 📝 文档
- **文档与示例**：新增 `HusRadius` 类型文档与 `ExpRadius` 示例
  - `ExpButton`、`ExpInput`、`ExpDateTimePicker` 新增尺寸示例
  - `ExpRectangle` 补充 `gradient` 文档与示例
  - 批量更新圆角属性相关文档与示例
