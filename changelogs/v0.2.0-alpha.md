# v0.2.0-alpha (2025-03-11)

## What's Changed

### ⚠️ 不兼容变更
- 未发现不兼容变更。

### ✨ 新功能
- **新增组件**：`DelAvatar`（头像），支持图标、图片、文字显示与尺寸配置
  - `DelCard`（卡片），支持标题、封面、内容与操作区自定义代理
- **新增主题**：`DelTheme` 新增 `DelCard` 主题对象
- **新增属性**：`DelDrawer` 新增 `drawerSize`，统一控制抽屉尺寸
- **组件增强**：`DelButton` 新增 `Type_Link` 链接按钮类型
