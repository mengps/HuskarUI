# v0.4.9.1-beta (2025-11-01)

## What's Changed

### ⚠️ 不兼容变更
- **属性重命名**：`HusCaptionBar` 的 `winIconVisible` / `winTitleVisible` / `returnButtonVisible` / `themeButtonVisible` / `topButtonVisible` / `minimizeButtonVisible` / `maximizeButtonVisible` / `closeButtonVisible` 统一改名为 `showWinIcon` / `showWinTitle` / `showReturnButton` / `showThemeButton` / `showTopButton` / `showMinimizeButton` / `showMaximizeButton` / `showCloseButton`
  - `HusMenu` / `HusContextMenu` / `HusSelect` / `HusAutoComplete` 的 `tooltipVisible` 改名为 `showToolTip`；`HusRate` 的 `toolTipVisible` 改名为 `showToolTip`
  - `HusMessage` / `HusNotification` 的 `closeButtonVisible` 改名为 `showCloseButton`
  - `HusTableView` 的 `columnGridVisible` / `rowGridVisible` / `columnHeaderVisible` / `rowHeaderVisible` 改名为 `showColumnGrid` / `showRowGrid` / `showColumnHeader` / `showRowHeader`
  - `HusToolTip` 的 `arrowVisible` 改名为 `showArrow`
- **属性类型变更**：`HusMenu.compactMode` 由 `bool` 改为枚举 `int`，取值 `Mode_Relaxed` / `Mode_Standard` / `Mode_Compact`
- **属性移除**：`HusMenu`、`HusContextMenu` 移除 `defaultMenuHeight`，菜单高度改为按内容自动计算

### 📌 迁移提示
- 全局搜索并替换 `xxxVisible` 为 `showXxx`；`compactMode: true` 改为 `compactMode: HusMenu.Mode_Compact`。

### ✨ 新功能
- **新增属性**：`HusIconButton` 新增 `orientation`（方向）
  - `HusContextMenu` / `HusMenu` 新增 `defaultMenuTopPadding`、`defaultMenuBottomPadding`
  - `HusTabView` 新增 `closeTabCallback` 回调
- **组件增强**：`HusSelect` 支持 `editable` 可编辑输入
  - `HusMenu` 支持标准模式与紧凑模式切换，菜单内容高度自动计算
  - `HusIconButton` 支持水平、垂直方向布局
  - 统一字体大小相关属性类型为 `int`，修正 `HusInput` 图标尺寸相关 token 命名

### 🐛 Bug 修复
- **行为修复**：修复 `HusMenu` 在紧凑模式下的判断与选中态逻辑

### 📝 文档
- **文档与示例**：`ExpMenu`、`ExpIconButton`、`ExpSelect`、`ExpContextMenu`、`ExpTabView`、`ExpTableView`、`ExpDateTimePicker` 等示例同步更新，修正多处文档描述错误

### ♻️ 其他改进
- **其他改进**：Gallery 新增 wiki 按钮与紧凑模式切换，更新预览图
