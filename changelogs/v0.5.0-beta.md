# v0.5.0-beta (2025-11-19)

## What's Changed

### ⚠️ 不兼容变更
- **属性重命名**：`HusMenu` 的 `menuBackgroundDelegate` 改名为 `menuBgDelegate`

### 📌 迁移提示
- 全局搜索 `menuBackgroundDelegate`，替换为 `menuBgDelegate`。

### ✨ 新功能
- **新增组件**：`HusQrCode`（二维码），支持 `text`、`margin`、`color`、`colorBg`、`colorMargin`、`errorLevel`、`icon` 等属性
- **新增属性**：`HusTableView` 新增 `rowHeightProvider` 行高提供函数
- **组件增强**：`HusTableView` 最大行高、最大宽度默认值由 `Number.NaN` 调整为 `Number.MAX_VALUE`
  - `HusMenu` 模型委托属性改用 `hasOwnProperty` 判断，避免误判
  - `HusWatermark` 不再持有 `networkAccessManager`
  - 移除 `HusMenu` 无用边框，`HusAsyncHasher` 移除无用接口
  - `HusCollapse` 完善自定义内容委托的引用方式

### 🐛 Bug 修复
- **行为修复**：修复 `HusRectangle` 圆角不生效
  - 修复 `HusMultiSelect` 后缀右边距计算错误
  - 修复 `HusMenu` 可能的意外情况
  - 抑制 `HusButton` / `HusCheckBox` 部分警告

### 📝 文档
- **文档与示例**：新增 `HusQrCode` 示例与文档 `ExpQrCode`
  - README 更新构建说明
  - `ExpCollapse`、`ExpTableView`、`ExpMenu` 等示例更新

### 🔧 构建与工具
- **构建改进**：支持 `find_package(HuskarUI REQUIRED)` 方式导入 (#42)
  - CMake 选项 `BUILD_HUSKARUI_IN_DEFAULT_LOCATION` 重命名为 `INSTALL_HUSKARUI_IN_DEFAULT_LOCATION`
  - 新增 `3rdparty/QR-Code-generator` 子模块
  - 新增 macOS 与 Qt `6.9.3` CI 工作流，并修复新构建流程导致的错误
- **开发工具**：Gallery `CodeBox` 增加代码复制按钮 (#43)

### ♻️ 其他改进
- **其他改进**：统一 Gallery 颜色与代码格式

### **Full Changelog**: https://github.com/mengps/HuskarUI/compare/v0.4.9.1-beta...v0.5.0-beta
