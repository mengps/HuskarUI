# v0.4.0-beta (2025-07-20)

## What's Changed

### ⚠️ 不兼容变更
- **全局重命名**：组件与主题统一由 `Del*` 改为 `Hus*`（49 个组件、32 个主题），旧名称不再提供
  - C++ 类型同步改名，如 `DelTheme`→`HusTheme`、`DelApi`→`HusApi`、`DelApp`→`HusApp`、`DelIcon`→`HusIcon`、`DelRectangle`→`HusRectangle`、`DelWindowAgent`→`HusWindowAgent`
  - QML 模块名由 `DelegateUI` 改为 `HuskarUI.Basic`，导入语句需同步修改
- **属性重命名**：`HusBreadcrumb` 的 `radiusBgItem` 改名为 `radiusItemBg`
- **属性类型变更**：`HusCaptionBar` 的 `winIcon` 由 `string` 改为 `url`；`HusResizeMouseArea.areaMarginSize`、`HusTourStep.radiusStepCard` 由 `real` 改为 `int`

### 📌 迁移提示
- 全局搜索 `Del` / `DelegateUI` 并替换为 `Hus` / `HuskarUI.Basic`，组件名、主题 token、C++ 类型与 QML 导入均需同步更新。

### ✨ 新功能
- **新增属性**：主题新增 `radiusBase` 变量与 `radiusPrimary`、`radiusPrimaryLG`、`radiusPrimarySM`、`radiusPrimaryXS`、`radiusPrimaryOuter` 圆角 token
  - `HusInputNumber` 新增 `alwaysShowHandler`，可始终显示增减按钮
- **新增 API**：`HusThemeFunctions` 新增 `genRadius()`，并新增 `HusRadiusGenerator` 半径序列生成类
- **组件增强**：组件字体、圆角与颜色默认值统一改为主题 token 驱动，主题预设色改用 `#Preset_*` 表达式
  - `HusRate` 完善半星动画判断并调整 `initValue` 默认值
  - `HusRectangle` 修改 `radius` 时同步发出关联信号
  - `HusScrollBar` 调整显示条件；`HusMoveMouseArea`、`HusResizeMouseArea` 拖拽边界默认值改用 `±Number.MAX_VALUE`

### 📝 文档
- **文档与示例**：新增 `CreatorPage`（创建新项目）与 `ThemeToken`（主题 token 展示）页面
  - 新增 `ExpCaptionBar`、`ExpMoveMouseArea`、`ExpResizeMouseArea` 示例，全部示例与文档随重命名更新

### 🔧 构建与工具
- **构建改进**：工程、插件与安装布局更名为 `HuskarUI` / `huskaruibasicplugin`，主题资源前缀改为 `:/HuskarUI`
  - 构建选项与辅助脚本统一为 `HUSKARUI_*` 与 `HuskarUIHelper.cmake`
  - 新增 Linux Qt `6.8.3` GCC CI，README 与 HuskarUI 品牌资源同步更新

### ♻️ 其他改进
- **其他改进**：代码格式与工程文件整理
