# v0.2.9-alpha (2025-05-04)

## What's Changed

### ⚠️ 不兼容变更
- **主题接口重命名**：`DelTheme.installThemePrimaryColor()` 更名为 `installThemePrimaryColorBase()`
  - `DelTheme.installThemePrimaryFontSize()` 更名为 `installThemePrimaryFontSizeBase()`
  - `DelTheme.installThemePrimaryFontFamilies()` 更名为 `installThemePrimaryFontFamiliesBase()`
- **属性重命名**：`DelAutoComplete` 的 `defaulPopupMaxHeight` 更正为 `defaultPopupMaxHeight`
- **枚举变更**：`DelWindow.SpecialEffect` 的 `DwmBlur`、`AcrylicMaterial`、`Mica`、`MicaAlt` 分别改名为 `Win_DwmBlur`、`Win_AcrylicMaterial`、`Win_Mica`、`Win_MicaAlt`，并新增 `Mac_BlurEffect`
- **方法重命名**：`DelOTPInput.inputAtIndex()` 更名为 `getInputAtIndex()`

### ✨ 新功能
- **新增组件**：`DelProgress`（进度条），支持线形、圆形、仪表盘三种类型，含状态、渐变、步骤与自定义格式化
- **新增主题**：`DelTheme` 新增 `DelProgress` 主题对象
- **新增属性**：`DelTheme` 新增 `textRenderType` 属性（`QtRendering` / `NativeRendering` / `CurveRendering`），统一文本渲染类型
  - `DelProgress` 新增 `type`、`status`、`percent`、`barThickness`、`steps`、`currentStep`、`gapDegree`、`useGradient`、`precision`、`formatter` 等属性
  - `DelAutoComplete` 新增 `clearIconSize`、`defaultOptionSpacing`，`DelMenu` 新增 `tooltipVisible`
- **新增方法**：`DelOTPInput` 新增 `setInput()`、`setInputAtIndex()`
- **新增 API**：`DelTheme` 新增 `installThemeColorTextBase()`、`installThemeColorBgBase()`，可直接设置主题文本色与背景色基础值
- **方法增强**：`DelWindow.setSpecialEffect()` 返回是否设置成功，并新增 `setMacSystemButtonsVisble()` 控制 macOS 系统按钮显隐
- **组件增强**：`DelDatePicker` 日期项排列改为按项大小自动计算，便于实现自定义日历
  - `DelWindow` 重构窗口特效逻辑，统一管理 Windows / macOS 下的特效切换
  - `DelApp` 内置字体资源，`DelIconText` 不再需要 `FontLoader`
  - `DelAutoComplete` 改进弹出、过滤与清空逻辑
  - `DelMenu` 的 `contentDelegate` 导出 `model` 数据

### 📝 文档
- **文档与示例**：新增 `DelProgress` 示例与文档
  - `ExpDatePicker` 增加自定义日历示例，Gallery 增加组件搜索功能
  - README 增加 Star 历史章节，Gallery 首页增加 Update 标识

### 🔧 构建与工具
- **构建改进**：新增 Windows MSVC2022 + Qt 6.8.3 的 CI 构建，并将 qwindowkit 更新至最新

### ♻️ 其他改进
- **其他改进**：删除无用代码、统一代码风格，并修复 `delapi.h` 在较低 Qt 版本下的构建错误
