# v0.5.1-beta (2025-11-28)

## What's Changed

### ⚠️ 不兼容变更
- 未发现不兼容变更。

### ✨ 新功能
- **新增组件**：`HusInputInteger`（整数输入框）
  - `HusSpin`（加载中），支持 `spinning`、`tip`、`percent`、`indicatorSize`、`indicatorItemCount` 等配置
- **新增主题**：`HusTheme` 新增 `HusSpin` 主题对象
- **新增属性**：`HusTimeline` 新增 `locale`
  - `HusDateTimePicker` 新增 `locale`
- **新增方法**：`HusTextArea` 新增 `scrollToBeginning()` / `scrollToEnd()`
- **新增 API**：`HusApp` 新增 `libName()`
- **组件增强**：`HusInputNumber` 的 `formatter` / `parser` 回调新增 `locale` 参数
  - 统一 `HusInput` / `HusInputNumber` / `HusInputInteger` 的行为与接口
  - `HusQrCode` 精简无用成员与头文件
  - `HusApp.libName` 在 Gallery 中统一使用

### 🐛 Bug 修复
- **行为修复**：修复 `HusProgress` 圆角可能小于 0
  - 修复 `HusButton` 部分情况下出现的警告
  - 修复脚手架生成项目的错误与多处文档描述错误

### 📝 文档
- **文档与示例**：新增 `HusInputInteger`、`HusSpin` 示例与文档
  - 更新 `ExpTextArea`、`ExpTimeline`、`ExpDateTimePicker`、`ExpQrCode` 等示例
  - README 优化 macOS 相关说明

### 🔧 构建与工具
- **构建改进**：提升 `find_package` 跨平台兼容性并修复 macOS 上 Gallery 打包错误 (#44)
  - 修复 Qt `6.10+` 构建错误
  - 更新 `3rdparty/qwindowkit` 子模块
  - `src/theme` 主题资源迁移至 `src/resources/theme`

### ♻️ 其他改进
- **其他改进**：Gallery 修复切换菜单时搜索图标消失并优化主题切换；代码风格整理
