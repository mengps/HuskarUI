# v0.5.2-beta (2025-12-12)

## What's Changed

### ⚠️ 不兼容变更
- **委托数据字段变更**：`HusRadioBlock` 默认 `radioDelegate` 读取的模型数据字段由 `icon` 改为 `iconSource`

### ✨ 新功能
- **新增组件**：`HusColorPicker`（颜色选择器弹出框）与 `HusColorPickerPanel`（颜色选择面板）
  - `HusAnimatedImage`（动态图）
  - `HusCheckerBoard`（棋盘格）
- **新增主题**：`HusTheme` 新增 `HusColorPicker` 主题对象
- **新增属性**：`HusButton` / `HusCaptionButton` 新增 `active` 属性
  - `HusIconButton` 新增 `iconFont`、`iconDelegate`
- **新增方法**：`HusTableView` 新增 `rowCount()`、`columnCount()`
- **组件增强**：`HusIconButton` 支持自定义图标字体与图标代理，并优化仅图标/无图标时的间距与高度
  - `HusInputInteger` / `HusInputNumber` 为 handler 添加背景色
  - `HusSelect` 移除多余间距
  - 优化 `HusPopconfirm`、`HusPopover`、`HusTimeline` 等组件的代码与效果

### 🐛 Bug 修复
- **行为修复**：`HusColorPickerPanel` 修复 hue 取值范围，统一为 `0~359`
  - `HusInputInteger` 修复 value 自动更新逻辑
  - `HusIconButton` 修复无图标时显示异常间距

### 📝 文档
- **文档与示例**：新增 `HusColorPicker` / `HusColorPickerPanel` / `HusCheckerBoard` / `HusAnimatedImage` 文档与 Gallery 示例

### 🔧 构建与工具
- **构建改进**：修复 macOS 工作流上传无效 release 文件的问题

### ♻️ 其他改进
- **其他改进**：为全部源文件补充 MIT LICENSE 许可头与许可证信息
  - Gallery 组件样式与页面刷新逻辑优化

### **Full Changelog**: https://github.com/mengps/HuskarUI/compare/v0.5.1-beta...v0.5.2-beta
