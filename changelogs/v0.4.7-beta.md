# v0.4.7-beta (2025-09-27)

## What's Changed

### ⚠️ 不兼容变更
- **主题 token 重命名**：`HusSwitch` 的 `colorCheckedBg`、`colorCheckedBgDisabled`、`colorCheckedBgHover`、`colorCheckedBgActive` 改名为 `colorBgChecked`、`colorBgCheckedDisabled`、`colorBgCheckedHover`、`colorBgCheckedActive`
  - `HusCopyableText`、`HusInput` 的 `colorSelectedText` 改名为 `colorTextSelected`

### 📌 迁移提示
- 自定义主题中全局搜索旧 token 名并替换为新名称。

### ✨ 新功能
- **新增组件**：`HusModal`（对话框）
- **新增主题**：`HusTheme` 新增 `HusModal` 主题对象
- **组件增强**：各组件统一内部图标判断逻辑并补充文档说明
  - `HusPopconfirm` 优化动画效果与内部主题源
  - `HusIconButton`、`HusPopconfirm`、`HusTourFocus`、`HusTourStep` 动画与样式微调
  - `HusShadow` 优化暗黑模式阴影
  - `HusTabView` 文本统一使用 `HusText` 渲染

### 🐛 Bug 修复
- **行为修复**：修复源码内嵌使用时平台判断不正确
  - 修复 `HusModal` 引用了错误的组件主题

### 📝 文档
- **文档与示例**：新增 `HusModal` 示例与文档
  - 补充组件文档跳转，示例 `Description` 在悬停链接时改变鼠标形状
  - `SettingsPage` 优化刻度加载逻辑

### 🔧 构建与工具
- **构建改进**：新增 `BUILD_HUSKARUI_IN_DEFAULT_LOCATION` 选项控制是否安装到默认目录 (#25)
  - 优化 CMake 选项描述文本

### ♻️ 其他改进
- **其他改进**：统一代码格式；`HusColorGenerator` 中 `qreal` 改为 `int`；`HusApi` 补充 Qt5 兼容处理

### **Full Changelog**: https://github.com/mengps/HuskarUI/compare/v0.4.6-beta...v0.4.7-beta
