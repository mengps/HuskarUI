# v0.5.9.0-beta (2026-03-29)

## What's Changed

### ⚠️ 不兼容变更
- **属性重命名**：`HusTabView` 的 `defaultTabBgRadius` 改名为 `radiusTabBg`，类型由 `int` 改为 `HusRadius`（支持四角独立设置）
- **主题 token 变更**：`HusTabView` 主题移除 `colorTabCardBgChecked`、`colorTabCardBgDark`、`colorTabCardBgCheckedDark`，改用 `colorTabCardBgActive`，并新增 `colorTabCardBorderActive`

### 📌 迁移提示
- 自定义 `HusTabView` 主题需将 `colorTabCardBgChecked` 替换为 `colorTabCardBgActive`，并移除 `colorTabCardBgDark`、`colorTabCardBgCheckedDark`。

### ✨ 新功能
- **新增组件**：`HusFrame`（框架），基于 `T.Frame`，支持边框宽度、背景色与圆角配置
  - `HusPage`（页面），基于 `T.Page`，提供统一页面背景色
  - `HusSegmented`（分段控制器）
- **新增主题**：`HusTheme` 新增 `HusSegmented` 主题对象
- **新增属性**：`HusTabView` 新增 `tabAlign` 对齐属性及枚举 `Align_Center` / `Align_Left` / `Align_Right`
  - `HusTabView` 新增 `defaultTabIconSpacing`、`defaultTabLeftPadding`、`defaultTabRightPadding`
  - `HusTabView` 新增 `colorTabCardBg`、`colorTabCardBgActive`、`colorTabCardBorder`、`colorTabCardBorderActive`
  - `HusTabView`、`HusCollapse` 的 `initModel` 支持 `contentDelegate` 模型内容代理
- **方法增强**：`HusTabView` 的 `get()`、`set()`、`setProperty()`、`append()`、`insert()`、`move()`、`remove()`、`positionViewAtIndex()` 补充参数类型标注
- **组件增强**：`HusTabView` 卡片式标签重构：支持标签文本对齐、左右内边距与卡片背景/边框颜色配置
  - `HusCollapse` 支持按模型项自定义内容代理
  - `HusCheckBox` 优化颜色过渡
  - `HusCaptionBar` 默认背景色由透明改为 `colorFillTertiary`

### 🐛 Bug 修复
- **行为修复**：`HusTabView` 修复 `initModel.contentDelegate` 在静态角色下的问题
  - `HusInputInteger` / `HusInputNumber` 修复 `selectAll()`、`selectWord()` 参数错误

### 📝 文档
- **文档与示例**：新增 `HusFrame`、`HusPage`、`HusSegmented` 文档与 Gallery 示例
  - 更新 `HusTabView`、`HusCollapse`、`HusTableView`、`HusInputInteger`、`HusInputNumber` 等组件文档与元信息
  - 修正 Gallery 示例中的文档描述错误

### 🔧 构建与工具
- **构建改进**：简化 `src/CMakeLists.txt` 源码目录结构
  - `src/designer` 元数据中新增 `HusSegmented`
  - 修复 Windows 打包脚本未拷贝依赖 dll 的问题 (#59)

### ♻️ 其他改进
- **其他改进**：代码风格规范（`HusBreadcrumb`、`HusText` 等）
