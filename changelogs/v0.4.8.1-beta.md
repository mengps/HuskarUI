# v0.4.8.1-beta (2025-10-02)

## What's Changed

### ⚠️ 不兼容变更
- **信号重命名**：`HusInputNumber` 的 `activedBefore` / `activedAfter` 信号改名为 `beforeActivated` / `afterActivated`

### ✨ 新功能
- **新增属性**：`HusInput` 新增 `clearEnabled`、`clearIconSource`、`clearIconSize`、`clearIconPosition`、`clearIconDelegate`、`bgDelegate`
  - `HusInputNumber` 新增 `clearEnabled`、`clearIconSource`、`clearIconSize`、`clearIconPosition`
  - `HusSelect` 新增 `clearEnabled`、`clearIconSource`
  - `HusDrawer` 新增 `closePosition`（含 `ClosePosition` 枚举）、`maskClosable`、`closeDelegate`
- **新增信号**：`HusInput`、`HusSelect` 新增 `clickClear()`
- **组件增强**：`HusInput` / `HusInputNumber` / `HusSelect` / `HusAutoComplete` 统一清除图标相关属性与交互
  - `HusDrawer` 支持配置关闭按钮的显示位置
  - 优化 `HusAutoComplete` / `HusInput` / `HusSelect` 主题中的图标颜色
  - `HusAcrylic` 改为通过 id 引用属性，避免重复表达式

### 📝 文档
- **文档与示例**：README 补充 MinGW 构建说明
  - `ExpDrawer`、`ExpInput`、`ExpInputNumber`、`ExpAutoComplete`、`ExpSelect`、`ExpShadow` 等示例同步更新

### ♻️ 其他改进
- **其他改进**：调整 `.gitignore` 与 Gallery `CMakeLists.txt` 配置
