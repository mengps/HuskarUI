# v0.5.6.1-beta (2026-01-23)

## What's Changed

### ⚠️ 不兼容变更
- 未发现不兼容变更。

### ✨ 新功能
- **新增属性**：`HusInput` 新增 `type`（`Outlined` / `Dashed` / `Borderless` / `Underlined` / `Filled`）、`showShadow`、`colorShadow`
  - `HusInputInteger` / `HusInputNumber` 新增 `type`、`showShadow`、`colorShadow`、`sizeHint`
  - `HusOTPInput` 新增 `type`、`showShadow`、`colorShadow`
- **新增方法**：`HusInputInteger` / `HusInputNumber` 新增 `getFullText()`
- **新增 API**：`HusApi` 新增 `clamp(value, min, max)` 接口
- **组件增强**：输入框 `parser` 使用 `HusApi.clamp` 将输入限制在 `min` / `max` 范围内
  - 数值格式化改用 `toLocaleString`，显示本地化数字格式
  - 调整输入框 handler 默认宽度（`24` → `22`）
  - 优化输入框颜色计算与代码结构

### 📝 文档
- **文档与示例**：补充输入框 `type` / `showShadow` / `sizeHint` 文档与示例
  - 优化提交历史时间线流程，补充默认值描述

### 🔧 构建与工具
- **构建改进**：优化 macOS / Windows 工作流打包与发布包名
