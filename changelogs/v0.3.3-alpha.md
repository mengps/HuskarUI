# v0.3.3-alpha (2025-06-02)

## What's Changed

### ⚠️ 不兼容变更
- 未发现不兼容变更。

### ✨ 新功能
- **新增组件**：`DelContextMenu`（上下文菜单），通常作为右键单击后弹出的菜单，提供 `initModel`、菜单尺寸/间距与子菜单偏移等配置，并提供 `clickMenu()` 信号
- **新增属性**：`DelMenu` 新增 `popupOffset`，并支持菜单项级 `iconDelegate`、`labelDelegate`、`backgroundDelegate`
  - `DelScrollBar` 新增 `minimumHandleSize`，用于限制最小滑块尺寸
  - `DelRate` 新增 `supportsHalfAnimation`，仅在支持时启用半星动画
- **新增 API**：`DelTheme` 新增 `installThemePrimaryAnimationBase()`，统一设置快/中/慢动画基础时长
  - `DelThemeFunctions` 新增 `onBackground()`，根据背景色计算可读前景色
- **组件增强**：单个菜单项的代理与组件级代理保持一致，便于单独定制菜单项
  - `DelMenu` 弹窗超出窗口时自动调整位置
  - `DelCheckBox`、`DelRate`、`DelTableView`、`DelTimePicker`、`DelTourFocus` 增加过渡动画 (#12)
  - `Index.json` 新增 `colorMain-1` 至 `colorMain-13` 中性色颜色表
  - `DelAcrylic` 与 Gallery 首页不再依赖 `Qt5Compat.GraphicalEffects`

### 🐛 Bug 修复
- **行为修复**：`DelTableView` 修复添加数据后行头未更新的问题
  - `DelTableView` 修复不透明与半透明颜色过渡导致的闪烁
  - `DelMenu` 修复子菜单背景色
  - Gallery 修复 `enabled` 带来的交互影响
- **动画修复**：`HomePage` 修复 3D 旋转卡片悬停抖动问题

### 📝 文档
- **文档与示例**：新增 `DelContextMenu` 示例与文档
  - `ExpButton` 文档补充默认值，`ExpTableView` 增加从 C++ 导入数据的示例
  - `CodeBox` 增加链接提示，Gallery 设置页新增动画基础速度设置
