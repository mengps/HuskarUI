# v0.3.1-alpha (2025-05-17)

## What's Changed

### ⚠️ 不兼容变更
- 未发现不兼容变更。

### ✨ 新功能
- **新增组件**：`DelCarousel`（走马灯/轮播图），支持自动播放、无限循环、拖拽切换与自定义指示器/箭头代理
- **新增主题**：`DelTheme` 新增 `DelCarousel` 主题对象
- **新增属性**：`DelCarousel` 新增 `initModel`、`currentIndex`、`position`、`speed`、`infinite`、`autoplay`、`autoplaySpeed`、`draggable`、`showIndicator`、`indicatorSpacing`、`showArrow` 及各类代理属性
  - `DelMenu` 新增 `menuIconDelegate`、`menuLabelDelegate`、`menuBackgroundDelegate`、`menuContentDelegate`，支持更细粒度的菜单定制
- **新增方法**：`DelCarousel` 新增 `swithTo()`、`swithToPrev()`、`swithToNext()` 切换方法
- **方法增强**：`DelCarousel.getSuitableIndicatorWidth()` 新增指示器最大宽度参数
- **组件增强**：逐步使用 `DelText` 替换原生 `Text`（`DelBadge` 与 Gallery 示例等）
  - 调整明暗模式基础色与按钮宽度

### 🐛 Bug 修复
- **行为修复**：`DelCarousel` 修复 `animationEnabled` 影响滚动的问题
  - `DelCard` 修复封面图超出边框的问题

### 📝 文档
- **文档与示例**：新增 `DelCarousel` 示例与文档
  - `ExpMenu` 增加菜单代理定制示例，`ExpBadge` 修正示例代码与描述
  - Gallery 主页文件结构调整并增加徽标，同步更新预览图

### **Full Changelog**: https://github.com/mengps/HuskarUI/compare/v0.3.0-alpha...v0.3.1-alpha
