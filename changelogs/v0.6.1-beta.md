# v0.6.1-beta (2026-06-13)

## What's Changed

### ⚠️ 不兼容变更
- **属性重命名**：`HusModal` 的 `descriptionDelegate` 改名为 `bodyDelegate`
- **信号变更**：`HusCollapse` 的信号 `actived(key)` 改为 `activated(key, index)`
- **委托接口变更**：`HusRadioBlock.radioDelegate` 中的 `required property var modelData` 改为 `required property var model`
- **回调数据变更**：`HusRadioBlock` 内部点击回调数据由 `button.modelData` 改为 `button.model`
- **默认值变更**：`HusRadioBlock.currentCheckedValue` 默认值从 `undefined` 改为 `null`

### ✨ 新功能
- **新增组件**：`HusSplitView`（分隔视图）完全新增，支持可折叠分隔栏与主题配置
- **新增主题**：`HusTheme` 新增 `HusSplitView` 主题对象
- **新增属性**：`HusButton` 新增 `borderWidth`
  - `HusLabel` 新增 `sizeHint`、`sizeRatio`
  - `HusCheckBox` 新增 `readOnly`
  - `HusDateTimePicker` / `HusDateTimePickerPanel` 新增 `visualYearTitle`、`visualMonthTitle`
- **新增方法**：`HusRadioBlock` 新增 `setCurrentIndex()`
  - `HusTabView` 新增 `setCurrentIndex()`
  - `HusTextArea` 新增 `clear()`
  - `HusWindow` 新增 `setWindowState()`，统一管理 `normal` / `minimized` / `maximized` / `fullscreen`
- **新增信号**：`HusTextArea` 新增 `editingFinished()`
- **新增 API**：`HusApi` 新增 `getWeekYearNumber()`，用于周模式跨年计算
- **方法增强**：`HusDateTimePicker.setDateTime()` / `setDateTimeString()` 新增可选参数 `emitSelected`
  - `HusDateTimePickerPanel.setDateTime()` / `setDateTimeString()` / `selectDateTime()` 新增可选参数 `emitSelected`
  - `HusMultiCheckBox.contains()` / `HusMultiSelect.contains()` 补充参数类型标注
- **组件增强**：`HusRadioBlock` 完善当前选中值同步逻辑
  - `HusTableView` 改进模型处理逻辑，完善返回类型标注与数据映射
  - `HusNotification` 新增折叠堆叠缩放动画并统一缓动效果
  - `HusInput` / `HusTextArea` 增强 placeholder 与隐式尺寸计算
  - `HusDateTimePickerPanel` 优化日期选择面板布局与实现
  - `HusLabel` 调整内边距与字体大小，配合 `sizeHint` 使用

### 🐛 Bug 修复
- **行为修复**：`HusTextArea` 修复隐式尺寸、禁用态文字/占位符颜色、代码缩进与部分 Qt 版本弹出 `ContextMenu` 的问题
  - `HusInput` 修复 placeholder 显示与隐式宽高计算
  - `HusDateTimePicker` 修复清空后无法选择当前日期
  - `HusDateTimePickerPanel` 修复周选择模式下年份显示、月份切换与跨年周数计算问题
  - `HusMenu` / `HusContextMenu` 修复菜单高度、首项间距和布局计算问题
  - `HusDrawer` 修复 `captionBar` 未定义时的判断逻辑，并调整标题区域高度行为
  - `HusProgress` 修复信息显示布局问题
  - `HusColorPicker` 修复颜色指示器宽度未铺满问题
  - `HusCheckBox` 修复复选框指示器背景显示异常
  - `HusCaptionBar` 修复返回按钮高度未正确继承的问题
  - `HusTreeView` 精简节点选择逻辑
- **动画修复**：`HusIconButton`、`HusMessage`、`HusNotification`、`HusSelect`、`HusSwitch`、`HusTimeline`、`HusBreadcrumb` 修复 loading 图标停止后旋转角度未重置的问题

### 📝 文档
- **文档与示例**：新增 `HusSplitView` 文档与 Gallery 示例
  - 补充 `HusSegmented`、`HusTabView`、`HusCheckBox`、`HusDateTimePicker`、`HusTextArea`、`HusModal`、`HusLabel`、`HusButton`、`HusAsyncHasher` 等文档
  - `ExpGroupBox` 新增自定义标签示例
  - `OverviewPage.qml` 新增组件总览预览页面
  - `HomePage.qml` 使用 `GridView` 替代 `Flickable`，提升展示性能
  - Gallery 更新组件版本与功能说明，示例页整体改进

### 🔧 构建与工具
- **构建改进**：Windows Qt CI 统一使用官方 action 的 MSVC 环境配置
  - macOS CI 工作流更新至 Qt `6.10.3` + clang
  - `CMake` 调整 `BUILD_HUSKARUI_ON_DESKTOP_PLATFORM` 默认值推导逻辑，避免覆盖用户显式配置
  - 项目版本从 `0.6.0` 提升到 `0.6.1`
- **开发工具**：`qmlpreviewer` PowerShell 脚本修复 QML 导入路径问题
  - `huskarui` 查询脚本增强组件匹配逻辑，并支持按分类搜索
  - `guide.metainfo.json` 增加 `category` 字段并补充更多组件元信息

### ♻️ 其他改进
- **其他改进**：`.gitignore` 新增 `.python-version` 忽略配置
  - `utils/extract_docs.py` 支持从文件路径提取组件分类信息
  - `skills/metainfo` 与示例元数据同步更新
  - 重构 `HusButtonBlock` / `HusRadioBlock`，移除多余 `Loader` 包装
