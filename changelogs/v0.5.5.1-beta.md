# v0.5.5.1-beta (2026-01-16)

## What's Changed

### ⚠️ 不兼容变更
- 未发现不兼容变更。

### ✨ 新功能
- **新增属性**：`HusCard` 新增 `hoverable`、`showShadow`、`colorShadow`
  - `HusContextMenu` 新增 `menu` 别名以访问内部菜单
  - `HusAutoComplete` 新增 `count` 只读属性
- **方法增强**：`HusWindow` 的 `setMacSystemButtonsVisible()`、`setWindowMode()`、`setSpecialEffect()` 添加参数类型标注
  - `HusColorPickerPanel` 的 `updateHSV()`、`floatToHex()`、`toHex()` 添加参数类型标注与返回值
- **组件增强**：`HusButton` 新增虚线按钮类型 `Type_Dashed`
  - `HusColorPickerPanel` 优化初始化逻辑
  - `HusShadow` 调整暗色主题下的阴影透明度
  - 优化主题颜色配置，补充尺寸比率文档

### 🐛 Bug 修复
- **行为修复**：`HusCaptionBar` 修复 macOS 下标题未绝对居中
  - 修复脚手架从源码创建项目错误，以及未 install 时无法找到头文件
  - `HusAvatar` 修正枚举名称拼写错误

### 📝 文档
- **文档与示例**：新增密码框示例，更新 `HusCard`、`HusIconText`、`HusContextMenu`、`HusAutoComplete` 等示例与文档

### 🔧 构建与工具
- **开发工具**：Designer 元信息文件的文本属性改为绑定国际化字符串

### ♻️ 其他改进
- **其他改进**：Gallery 与组件代码格式统一
