# v0.4.3-beta (2025-08-20)

## What's Changed

### ⚠️ 不兼容变更
- **属性移除**：`HusAutoComplete` 移除 `clearIconSource`、`clearIconSize`、`clearIconPosition`、`clearIconDelegate`，改用 `clearEnabled` 控制清除按钮
- **属性重命名**：`HusDatePicker` 的 `dateFormat` 改名为 `format`
  - `HusSelect` 的 `defaulPopupMaxHeight` 更正为 `defaultPopupMaxHeight`

### 📌 迁移提示
- `HusAutoComplete` 的清除按钮改用 `clearEnabled` 控制；`HusDatePicker` 的日期格式改用 `format`。

### ✨ 新功能
- **新增组件**：`HusMultiSelect`（下拉多选器），继承 `HusSelect`，支持标签代理与多选
- **新增主题**：`HusMultiSelect`
- **新增属性**：`HusAutoComplete` 新增 `clearEnabled`；`HusTimePicker` 新增 `initTime`
  - `HusImagePreview` 新增 `sourceDelegate`；`HusSelect` 新增只读属性 `active` 与 `themeSource`
- **新增方法**：`HusTimePicker` 新增 `setTime()`；`HusApi` 新增 `dateFromString()` 字符串转日期接口
- **方法增强**：`HusApi.setClipbordText()` 改为返回 `bool`；`HusApi.getWeekNumber()` 参数改为 `QDateTime`
- **组件增强**：重构主题系统：主题 JSON 统一改为 `__style__` 样式分组，组件新增 `themeSource` 样式源以分离样式
  - `HusAutoComplete` 支持键盘操作，优化选中逻辑与弹出动画

### 🐛 Bug 修复
- **行为修复**：`HusAutoComplete` 修复清空输入时弹窗高度异常
  - `HusTableView` 修复网格线被内容覆盖的问题

### 📝 文档
- **文档与示例**：新增 `HusMultiSelect` 示例与文档；Gallery 示例统一使用 `HusText`
  - 修正 `HusImagePreview` 文档描述；Gallery 代码块按钮图标更新

### 🔧 构建与工具
- **构建改进**：修复 macOS 构建错误
