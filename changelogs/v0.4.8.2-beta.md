# v0.4.8.2-beta (2025-10-14)

## What's Changed

### ⚠️ 不兼容变更
- **信号参数变更**：`HusMenu` / `HusContextMenu` / `HusBreadcrumb` 的 `clickMenu` 信号参数由 `(deep, menuKey, menuData)` 统一为 `(deep, key, keyPath, data)`

### ✨ 新功能
- **新增组件**：`HusPopover`（气泡显示框）
- **新增主题**：`HusTheme` 新增 `HusPopover` 主题对象，`HusPopconfirm` 主题继承 `HusPopover`
- **新增属性**：`HusInput` 的 `clearEnabled` 类型由 `bool` 扩展为 `var`，支持按激活状态显示清除按钮
  - `HusInputNumber` 的 `clearEnabled` 支持激活状态控制
- **新增方法**：`HusTableView` 新增 `getCellData()`、`setCellData()`
  - `HusMenu` 新增 `setData()`、`setDataProperty()`
- **组件增强**：`HusInput` 在只读、失焦时隐藏清除图标
  - `HusSelect` / `HusMultiSelect` 完善清除按钮可用性，多选默认禁用清除
  - `HusMenu` 相关组件的弹窗逻辑与信号处理统一

### 🐛 Bug 修复
- **行为修复**：修复 `HusSelect` 禁用后清除按钮仍生效
  - 修复 `HusMenu` 菜单内容超出部分未裁剪
  - 修复 `HusDrawer` 显示时仍响应系统按钮
  - 修复 `HusInputNumber` 描述错误并同步 Gallery 分类
  - 修复 `ThemeToken` 中多余的清除图标

### 📝 文档
- **文档与示例**：新增 `HusPopover` 示例 `ExpPopover`
  - README 更新 wiki 相关内容，补充 `HusMenu`、`HusTableView` 接口文档

### 🔧 构建与工具
- **构建改进**：更新 `3rdparty/qwindowkit` 子模块

### ♻️ 其他改进
- **其他改进**：Gallery 增加 ESC 键处理并自动生成状态；`ExpMenu`、`ExpBreadcrumb`、`ExpContextMenu`、`ExpTableView` 等示例更新

### **Full Changelog**: https://github.com/mengps/HuskarUI/compare/v0.4.8.1-beta...v0.4.8.2-beta
