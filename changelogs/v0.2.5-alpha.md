# v0.2.5-alpha (2025-03-31)

## What's Changed

### ⚠️ 不兼容变更
- **枚举迁移**：`DelButton` 的 `IconPosition` 枚举（`Position_Start`、`Position_End`）迁移至 `DelIconButton`，引用处需改为 `DelIconButton.Position_Start` / `DelIconButton.Position_End`

### ✨ 新功能
- **新增组件**：`DelTableView`（表格），支持列头/行头、网格线、行列尺寸调整与列排序筛选
  - `DelTag`（标签），支持状态色与预设颜色，可自定义图标并通过 `close()` 信号响应关闭
- **新增主题**：`DelTheme` 新增 `DelTableView`、`DelTag` 主题对象
- **新增属性**：`DelIconButton` 新增 `loading`
  - `DelRectangle` 新增 `style` 边框线样式
- **新增方法**：`DelThemeFunctions.genColor()` 新增接收预设值（`int preset`）的重载
- **组件增强**：`DelButton`、`DelIconButton` 等组件小幅样式与布局调整

### 🐛 Bug 修复
- **行为修复**：`DelPagination` 首次加载时补发 `currentPageIndexChanged()` 信号

### 📝 文档
- **文档与示例**：新增 `DelTableView`、`DelTag` 示例与文档
  - 补充 `DelIconButton` 的 `loading` 与 `DelRectangle` 边框样式文档

### ♻️ 其他改进
- **其他改进**：调整 `DelButton`、`DelCopyableText`、`DelTimeline` 主题颜色，Gallery 界面微调

### **Full Changelog**: https://github.com/mengps/HuskarUI/compare/v0.2.4-alpha...v0.2.5-alpha
