# v0.2.8-alpha (2025-04-24)

## What's Changed

### ⚠️ 不兼容变更
- **代理移除**：`DelMenu` 移除 `menuDelegate` 组件代理，改由菜单数据的 `contentDelegate` 字段自定义菜单项内容

### ✨ 新功能
- **新增组件**：`DelDatePicker`（日期选择），支持年、季、月、周、日五种选择模式
- **新增主题**：`DelTheme` 新增 `DelDatePicker` 主题对象
- **新增属性**：`DelDatePicker` 新增 `pickerMode`、`initDate`、`currentDate`、`dateFormat`、`placeholderText`、`dayDelegate` 等属性
  - `DelWindow` 新增 `contentHeight` 属性
  - `DelOTPInput` 新增 `currentInput`、`itemPasswordCharacter` 属性
- **新增方法**：`DelTableView` 新增 `appendRow()`、`insertRow()`、`removeRow()`、`moveRow()`、`setRow()`、`getRow()`、`clear()` 等行操作接口
  - `DelOTPInput` 新增 `inputAtIndex()`
- **新增 API**：`DelApi` 新增 `getWeekNumber()`，用于获取日期对应周数
  - `DelThemeFunctions` 新增 `genColorString()`
- **组件增强**：`DelMenu` 菜单项支持通过 `contentDelegate` 定制内容，并改进菜单展开与选中逻辑

### 🐛 Bug 修复
- **行为修复**：`DelRadioBlock` 修复 `shape` 可能覆盖组件自身取值的问题

### 📝 文档
- **文档与示例**：新增 `DelDatePicker` 示例与文档
  - `ExpTableView` 补充模型行操作接口文档，`ExpInput`、`ExpOTPInput` 文档同步更新
  - 修正 `ExpDatePicker` 示例中的错误

### ♻️ 其他改进
- **其他改进**：C++ 侧增加若干 Qt5 兼容处理（窗口代理、颜色/尺寸生成器、系统主题辅助等）
  - 一些代码格式调整
