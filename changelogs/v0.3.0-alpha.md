# v0.3.0-alpha (2025-05-10)

## What's Changed

### ⚠️ 不兼容变更
- **信号变更**：`DelRadioBlock` 的 `clicked` 信号由 `clicked(radioData)` 改为 `clicked(index, radioData)`

### ✨ 新功能
- **新增组件**：`DelBadge`（徽标数），支持数字、图标、点状徽标与溢出计数
  - `DelButtonBlock`（按钮块），将多个按钮组织成块，支持自适应/固定尺寸与自定义按钮代理
- **新增属性**：`DelBadge` 新增 `badgeState`、`presetColor`、`count`、`iconSource`、`dot`、`showZero`、`overflowCount`、`colorBg`、`colorBorder`、`colorText` 等属性
  - `DelButtonBlock` 新增 `model`、`size`、`buttonWidth`、`buttonHeight`、`buttonLeftPadding` 等尺寸与委托属性
- **新增信号**：`DelButtonBlock` 新增 `pressed(index, buttonData)`、`released(index, buttonData)`、`clicked(index, buttonData)` 信号
- **组件增强**：`DelRadioBlock` 单选项支持图标，默认代理改用 `DelIconButton`
  - `DelButton` 增加禁用态边框颜色

### 🐛 Bug 修复
- **行为修复**：`DelProgress` 修复条形步骤进度条未使用 `barThickness` 作为矩形高度
  - `DelAutoComplete` 按住时不再显示 tooltip
  - `DelTableView` 修复勾选框偶发显示错误状态的问题
  - `DelMenu` 修复修改 `initModel` 导致 `ListView` 多次创建的问题

### 📝 文档
- **文档与示例**：新增 `DelBadge`、`DelButtonBlock` 示例与文档
  - 修正 `ExpProgress` 文档描述与 `README` 拼写错误，并更新 Gallery 主页预览图
  - Gallery 更新 `DelRadioBlock` 相关设置与 `DelMenu` 子菜单排序

### **Full Changelog**: https://github.com/mengps/HuskarUI/compare/v0.2.9-alpha...v0.3.0-alpha
