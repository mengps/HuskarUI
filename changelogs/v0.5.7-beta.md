# v0.5.7-beta (2026-02-04)

## What's Changed

### ⚠️ 不兼容变更
- **属性重命名**：`HusMenu` 的 `defaultSelectedKey` 更名为 `defaultSelectedKeys`，值需为 key 数组

### 📌 迁移提示
- 全局搜索 `defaultSelectedKey`，替换为 `defaultSelectedKeys`（值写成数组，如 `['menuKey']`）。

### ✨ 新功能
- **新增组件**：`HusTransfer`（穿梭框），支持源/目标列表、搜索、分页、单向移动与自定义标题/操作按钮
- **新增主题**：`HusTheme` 新增 `HusTransfer` 主题对象
- **新增属性**：`HusTableView` 新增 `columnResizable`、`rowResizable`、`defaultCheckedKeys`、`columnHeaderTitleDelegate`
  - `HusCheckBox` 新增 `sizeHint`、`sizeRatio`、`elide`
  - `HusTreeView` 新增 `forceUpdateCheckState`、`nodeIconFont`、`colorNodeIcon`
  - `HusMultiSelect` 新增 `defaultSelectedKeys`
  - `HusTableView` 主题新增 `colorBgDisabled`，`HusTreeView` 主题新增 `colorNodeIcon`
- **新增方法**：`HusMultiSelect` 新增 `insertTag()`、`appendTag()`，按 key 插入/追加标签
- **方法增强**：`HusMenu` 的 `get()`、`set()`、`setProperty()`、`setData()`、`setDataProperty()`、`move()`、`insert()`、`append()`、`remove()`、`gotoMenu()` 等补充参数类型标注
  - `HusMultiSelect`、`HusTableView` 的若干公共方法补充参数类型标注
  - `HusTableView.scrollToRow()` 新增可选参数 `mode`（默认 `TableView.AlignVCenter`）
- **组件增强**：`HusCheckBox` 支持 `sizeHint` / `sizeRatio` 尺寸体系，指示器、字体与间距随比例缩放
  - `HusTableView` 支持自定义列头标题代理（`columnHeaderTitleDelegate`）与模型 `enabled` 支持，并改进初始化与选择逻辑
  - `HusTreeView` 支持强制更新勾选状态，支持节点图标字体与颜色配置
  - `HusMultiSelect` 支持默认选中项与标签插入位置控制
  - `HusPagination` 的 `pageTotal` 改为只读，并补充页数变化时的索引修正
  - `HusColorPicker` 微调尺寸

### 🐛 Bug 修复
- **行为修复**：`HusTableView` 修复 `checkedKeys` 不正确与复选框选择功能
  - `HusSpin` 修复某些情况下进度失效
  - `HusTreeView` 修复 Qt 6.9 以下时选中状态不正确
  - `HusEmpty` 修复默认 `imageStyle` 引用不存在的枚举值
  - `HusDivider` / `HusTreeView` 默认线宽按 `Screen.devicePixelRatio` 缩放，避免线条粗细变化 (#49)
  - `HusColorPickerPanel` 修复类型注解导致的错误类型转换

### 📝 文档
- **文档与示例**：新增 `docs/` 文档目录，收录 87 篇组件、主题、函数与工具类文档（由 Gallery 示例提取生成）
  - 新增 `HusTransfer` 组件文档与 Gallery 示例
  - README 补充组件文档链接与 AI 辅助开发说明
  - 修正文档链接与类型说明（`list` → `array`）

### 🔧 构建与工具
- **构建改进**：macOS CI 工作流更新 Qt 版本
  - `src/designer` 元数据中新增 `HusTransfer`
- **开发工具**：新增文档提取与 Markdown 生成工具 `utils/extract_docs.py`、`utils/generate_markdown.py`、`utils/main.py`
  - 新增 `ai_tools/HuskarUIExpert` 技能文档与 `query_metainfo.py` 组件元信息查询工具
  - `guide.metainfo.json` 迁入技能目录并补充组件元信息

### ♻️ 其他改进
- **其他改进**：`HusDateTimePicker`、`HusInputInteger`、`HusInputNumber` 代码结构调整
  - `.gitignore` 忽略 Trae 生成的 `*.trae` 文件
