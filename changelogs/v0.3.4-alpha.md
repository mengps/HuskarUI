# v0.3.4-alpha (2025-06-12)

## What's Changed

### ⚠️ 不兼容变更
- 未发现不兼容变更。

### ✨ 新功能
- **新增组件**：`DelBreadcrumb`（面包屑导航），支持自定义分隔符与下拉菜单项
- **新增主题**：`DelBreadcrumb`
- **新增 API**：C++ 属性声明宏新增指针属性版本 `DEL_PROPERTY_P`、`DEL_PROPERTY_P_INIT`
- **组件增强**：`DelPagination` 上/下一页按钮与向前/向后 5 页图标增加颜色过渡和平滑淡入
  - `DelAutoComplete`、`DelPagination` 增加颜色过渡动画
  - `DelPopup`、`DelRate` 调整阴影效果

### 🐛 Bug 修复
- **动画修复**：`DelMenu` 修复宽度动画丢失
  - `DelPagination` 修复上/下一页按钮背景色过渡闪烁
- **行为修复**：`DelTableView` 修复主题中选中悬停颜色错误

### 📝 文档
- **文档与示例**：新增 `DelBreadcrumb` 示例与文档，补充 `TableView`、`ContextMenu`、`Menu` 文档
  - Gallery 新增主题切换动画，并优化设置页面与标签
  - README 新增 Roadmap 章节

### ♻️ 其他改进
- **其他改进**：统一代码格式；修正文档错误
