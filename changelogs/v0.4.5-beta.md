# v0.4.5-beta (2025-08-31)

## What's Changed

### ⚠️ 不兼容变更
- **信号重命名**：`HusMessage` 的 `messageClosed(key)` 信号改名为 `closed(key)`

### 📌 迁移提示
- 全局搜索 `messageClosed`，替换为 `closed`。

### ✨ 新功能
- **新增组件**：`HusShadow`（统一阴影组件），基于 `MultiEffect` 封装主题化阴影效果
- **新增主题**：`HusTheme` 新增 `HusNotification` 主题对象
- **新增属性**：`HusMessage` 新增 `messageDelegate`、`defaultIconSize`、`spacing`、`topMargin`
- **新增方法**：`HusMessage` 新增 `getMessage(key)`，按 key 获取消息数据
- **新增 API**：`HusApi` 新增 `setWindowState()`，统一管理窗口最小化/最大化/还原状态
- **组件增强**：`HusNotification`（通知提醒框）完整实现，支持位置、堆叠、进度条与悬停暂停
  - 使用 `HusShadow` 统一 `HusDrawer`、`HusPopup`、`HusRate`、`HusToolTip` 的阴影实现
  - `HusDateTimePicker` 优化清空逻辑

### 🐛 Bug 修复
- **行为修复**：修复 `HusDateTimePicker` 初始时间（时/分/秒）未置零的问题
  - 修复 `HusCaptionBar` 窗口最大化/最小化后无法还原的问题
  - 修复 `HusProgress` 默认宽度导致布局无效的问题 (#21)
  - 修复 `HusCollapse` 负值缓存导致的警告 (#23)

### 📝 文档
- **文档与示例**：新增 `HusNotification` 示例与文档
  - 更新 README 徽章与特性说明，修复中英 README 切换问题
  - 修正 `ExpMultiSelect` 文档描述 (#22)，修复 `ExpDrawer` 示例异步加载导致高度不正确

### ♻️ 其他改进
- **其他改进**：优化 Gallery 主题切换表现，设置页统一使用 `HusShadow` 阴影

### **Full Changelog**: https://github.com/mengps/HuskarUI/compare/v0.4.4.1-beta...v0.4.5-beta
