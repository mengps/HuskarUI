# v0.5.5-beta (2026-01-12)

## What's Changed

### ⚠️ 不兼容变更
- **属性重命名**：`HusSystemThemeHelper` 的 `themeColor` 属性改名为 `accentColor`
- **方法重命名**：`HusSystemThemeHelper.getThemeColor()` 改名为 `getAccentColor()`

### 📌 迁移提示
- 全局搜索 `HusSystemThemeHelper.themeColor` / `getThemeColor()`，替换为 `accentColor` / `getAccentColor()`。

### ✨ 新功能
- **新增属性**：`HusAutoComplete`、`HusMultiSelect`、`HusSelect`、`HusPagination`、`HusOTPInput` 新增 `sizeHint` 尺寸提示及 `sizeRatio`
  - `HusMenu` 新增 `selectedKey`
  - `HusCaptionBar` 新增 `winNavButtonsDelegate` 代理
  - `HusDateTimePicker` / `HusDateTimePickerPanel` 新增当前文本颜色主题 token
- **新增 API**：新增 `HusRouter` 路由实现（含 `HusRouterHistory`），支持页面历史管理
- **组件增强**：`HusApp` 创建时自动初始化
  - 统一 `HusTimeline`、`HusTreeView`、`HusRadio` 等组件的代码结构与主题读取方式

### 🐛 Bug 修复
- **行为修复**：`HusBadge` 修复父组件覆盖问题
  - `HusTimeline` 修复线条颜色引用错误
  - `HusTreeView` 修正内部属性名拼写（`vaild` → `valid`）

### 📝 文档
- **文档与示例**：新增 `HusRouter` 文档与示例
  - 更新 README 中 `HusApp` 初始化说明与 Designer 预览图，补充 `HusAsyncHasher` 等文档

### 🔧 构建与工具
- **构建改进**：更新 `3rdparty/qwindowkit` 至最新
  - CI 打包时拷贝 `HuskarUI.Impl` 模块
  - 修复 macOS Qt 低版本编译错误并提升 Gallery 帧率 (#50)
  - `.gitignore` 忽略 VS/CMake 生成文件并修正预设文件忽略规则
- **开发工具**：新增 Qt Designer 元信息文件，支持在 Designer 中展示组件

### ♻️ 其他改进
- **其他改进**：`HusWindowAgent` 迁移至 `HuskarUI.Impl` 模块，`HusWindow` 随之依赖该模块
  - 统一代码格式，脚手架补充 `HuskarUIImplPlugin` 库

### **Full Changelog**: https://github.com/mengps/HuskarUI/compare/v0.5.4-beta...v0.5.5-beta
