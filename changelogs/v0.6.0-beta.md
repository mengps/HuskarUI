# v0.6.0-beta (2026-04-23)

## What's Changed

### ⚠️ 不兼容变更
- **信号重命名**：`HusMultiSelect` 的信号 `removeTag(option)` 更名为 `deselect(option)`
- **属性重命名**：`HusPagination` 的 `prevButtonTooltip` / `nextButtonTooltip` 更名为 `prevButtonToolTip` / `nextButtonToolTip`

### ✨ 新功能
- **新增组件**：`HusGroupBox`（分组框）、`HusMultiCheckBox`（多选复选框）
- **新增主题**：`HusTheme` 新增 `HusGroupBox`、`HusMultiCheckBox` 主题对象
- **新增属性**：`HusSegmented` 新增 `defaultItemHeight`
  - `HusPagination` 的 `defaultButtonWidth` / `defaultButtonHeight` 支持设为 `'auto'` 自动计算按钮宽高
  - `HusSelect` 新增 `toolTipDelegate`，可自定义弹出项的工具提示
  - `HusLabel` 背景新增圆角支持，`radiusBg` 默认取主题 `radiusBg`
  - `HusMultiSelect` 支持禁用态标签文字颜色
- **新增方法**：`HusTableView` 新增 `setColumnVisible()`，支持列的显示/隐藏
- **方法增强**：`HusTableView` 的 `getRow()`、`insertRow()`、`moveRow()`、`removeRow()`、`setRow()`、`getCellData()`、`setCellData()` 补充参数类型标注
- **组件增强**：`HusCheckBox` 优化指示器定位与文本对齐，支持镜像布局与居中对齐，并按启用状态调整指示器颜色
  - `HusInputNumber` 编辑文本时即钳制数值上限并格式化，移除 `parser` 中的 clamp 限制
  - `HusDivider`、`HusMessage` 补充禁用态颜色，并同步更新相关主题 Token
  - `HusMenu` 移除重复点击判断，`HusContextMenu` 可重复点击同一菜单项
  - `HusTransfer` 为子组件补齐 `animationEnabled` 绑定
  - `HusTextArea` 精简属性定义与行为动画代码

### 🐛 Bug 修复
- **行为修复**：修复 `HusTextArea` 滚动条不显示/失效的问题 `(#62)`
  - 修复 `HusMenu` 菜单项点击展开异常
  - 修复 `HusCheckBox` 指示器颜色未随启用状态变化
  - 修复 Gallery 菜单循环跳转导致重复触发
- **动画修复**：修复 `HusImagePreview` 缩放、旋转后图像位置计算错误

### 📝 文档
- **文档与示例**：新增 `HusGroupBox`、`HusMultiCheckBox` 文档与 Gallery 示例
  - Gallery 新增 `GradientFlowEffect` 渐变流动效果并替换原有 `ShaderEffect`
  - `HomePage` 重构，增加组件分类与过滤功能
  - 更新中英文 README 的 AI 助手说明与亮/暗预览图

### 🔧 构建与工具
- **构建改进**：`CMake` 添加插件源文件支持并更新 QML 模块配置
  - 项目版本更新至 `0.6.0`
- **开发工具**：新增 `agent` 智能体技能目录（`huskarui` 组件查询、`qmlpreviewer` 预览），替代原 `ai_tools`
  - `utils/extract_docs.py`、`utils/main.py` 补充新组件的文档提取配置

### ♻️ 其他改进
- **其他改进**：移除冗余的单例实例代码与重复的 `HusApp` 单例注册
