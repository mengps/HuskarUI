# v0.7.0.1-beta (2026-10-17)

## What's Changed

### ⚠️ 不兼容变更
- **属性移除**：`HusButton`、`HusCard`、`HusFrame`、`HusGroupBox`、`HusLabel` 移除 `borderWidth`，边框宽度改由 `borderBg.width`（`HusBorder`）控制
  - `HusButton`、`HusCard`、`HusFrame`、`HusGroupBox`、`HusCollapse`、`HusTag`、`HusSegmented`、`HusInput`、`HusSelect`、`HusTextArea`、`HusBadge`、`HusTransfer`、`HusColorPicker`、`HusColorPickerPanel`、`HusDateTimePickerPanel` 移除 `colorBorder`，改用 `borderBg.color`（`HusLabel` 保留 `colorBorder`）
- **类型重命名**：C++/QML 边框类型 `HusPen` 更名为 `HusBorder`，`HusRectangle.border` 等类型同步变更
- **属性只读化**：`HusRadioBlock.currentCheckedValue` 由可写属性改为只读计算属性，由 `currentCheckedIndex` 与 `model` 推导

### 📌 迁移提示
- 全局搜索 `borderWidth`、`colorBorder`，分别替换为 `borderBg.width`、`borderBg.color`；搜索 `HusPen`，替换为 `HusBorder`。

### ✨ 新功能
- **新增组件**：`HusImagePreviewPanel`（图片预览面板），可独立使用，支持缩放、旋转、翻转与自定义代理
- **新增主题**：`HusTheme` 新增 `HusImagePreview`、`HusImagePreviewPanel` 主题对象
- **新增属性**：`HusDateTimePicker` / `HusDateTimePickerPanel` 新增 `pickerMonthTable`，支持自定义月份名称
  - 新增 `HusBorder` 类型的 `borderBg` 属性，覆盖 `HusButton`、`HusCard`、`HusFrame`、`HusGroupBox`、`HusLabel`、`HusCollapse`、`HusTag`、`HusSegmented`、`HusInput`、`HusSelect`、`HusTextArea`、`HusTransfer`、`HusToolTip`、`HusBadge`、`HusColorPicker`、`HusColorPickerPanel`、`HusDateTimePickerPanel`、`HusImagePreviewPanel`
  - `HusImagePreview` 新增 `panel` 别名，可访问内部预览面板
- **新增方法**：`HusImagePreview` 新增 `toCenter()`，用于将图像回中
- **新增 API**：新增 `DoubleSpinBox` 类型（Qt < 6.11 内置 `QQuickDoubleSpinBox` 实现），为数字输入提供浮点步进能力
- **方法增强**：`HusImagePreview` 的 `get()`、`append()` 等补充参数类型标注
- **组件增强**：`HusInputNumber` 基于 `DoubleSpinBox` 重构，统一浮点输入、格式化与解析
  - `HusImagePreview` 拆分内部面板，代理属性改为别名，支持与 `HusImagePreviewPanel` 组合复用
  - `HusCollapse` 新增禁用态支持，主题新增 `colorBgDisabled`、`colorBorderDisabled` 等 Token
  - `HusCopyableText` 支持禁用态文字颜色
  - `HusTag`、`HusSegmented`、`HusCollapse`、`HusCard` 等组件边框统一由 `HusBorder` 管理
  - `HusIconButton` 的 `iconSize` 跟随 `sizeRatio` 缩放
  - `HusImage` 改用 `HusTheme.HusImage` 主题对象读取颜色
  - `HusColorPicker` 暴露 `borderBg` 别名
  - `HusInputInteger` / `HusInputNumber` 的 `formatter`、`parser` 改为原生 `SpinBox` 函数别名

### 🐛 Bug 修复
- **行为修复**：修复 `HusTreeView` 默认可选中导致初始化选中项错误
  - 修复 `HusImagePreview` 的 `prevDelegate` 错误别名到 `sourceDelegate` 的问题
  - 修复 `HusRectangle` 使用父类元对象获取自身槽索引的错误

### 📝 文档
- **文档与示例**：新增 `HusBorder`、`HusImagePreviewPanel` 文档与 Gallery 示例
  - 补充/修正 `HusTag`、`HusCollapse`、`HusSegmented` 边框属性，`HusDateTimePicker` 月份表，`HusInputInteger` / `HusInputNumber` 数值范围等文档
  - README 新增 DeepWiki 徽章，并修复 Star 历史图表链接 `(#67)`
  - 新增 `AGENTS.md`、`CLAUDE.md` 项目说明文件

### 🔧 构建与工具
- **构建改进**：修复非 Windows 平台 Debug 构建下 QML 插件无法加载的问题 `(#68)`
  - 新增 `DoubleSpinBox` 条件编译（Qt < 6.11 且存在私有头时启用）
  - 更新 `qwindowkit` 子模块
  - 项目版本更新至 `0.7.0.1`
- **开发工具**：`agent/` 目录迁移为 `.agents/`

### ♻️ 其他改进
