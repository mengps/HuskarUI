# v0.4.5.2-beta (2025-09-18)

## What's Changed

### ⚠️ 不兼容变更
- 未发现不兼容变更。

### ✨ 新功能
- **新增属性**：`HusCaptionBar` 新增 `winExtraButtonsDelegate`，标题栏的主题、置顶等扩展按钮可单独定制
- **方法增强**：`HusTourStep.recalcPosition()` 新增可选参数 `delay`
- **组件增强**：`HusCaptionBar` 将扩展按钮从 `winButtonsDelegate` 拆分至 `winExtraButtonsDelegate`，窗口按钮与扩展按钮可分别定制
  - `HusTourFocus` / `HusTourStep` 优化高亮焦点与步骤卡片显示效果，修复卡片超出窗口的问题 (#20)
  - 移除漫游着色器，改用 Canvas 绘制遮罩与高亮区域，并统一部分尺寸属性为 `int` 类型
  - `HusPopup` 优化过渡动画

### 🐛 Bug 修复
- **行为修复**：修复 `HusCaptionBar` 更改字体大小后高度不正确
  - 修复 Gallery 创建页在空项目时仍显示共享库

### 📝 文档
- **文档与示例**：补充 `HusTourStep`、`HusTourFocus` 属性文档与示例
  - 更新 Gallery 组件列表与示例描述

### 🔧 构建与工具
- **构建改进**：修复 Linux CI 包后缀错误；Android 构建添加 openssl 库

### ♻️ 其他改进
- **其他改进**：移除未使用的头文件；优化 Gallery 移动平台表现
