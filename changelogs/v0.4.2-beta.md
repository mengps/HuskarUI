# v0.4.2-beta (2025-08-07)

## What's Changed

### ⚠️ 不兼容变更
- 未发现不兼容变更。

### ✨ 新功能
- **新增组件**：`HusImage`（可预览图片，继承 `Image`，支持加载/失败占位与预览列表）
  - `HusImagePreview`（图片预览弹窗，支持缩放与旋转）
- **新增主题**：`HusImage`
- **新增属性**：`HusWindow` 新增 `isDesktopPlatform`，用于判断桌面平台
- **组件增强**：`HusWindow` 仅在桌面平台初始化窗口代理，非桌面平台可正常创建与设置窗口

### 🐛 Bug 修复
- **行为修复**：Gallery `CodeBox` 修复异步加载导致的组件错误
  - 修正 `ExpCarousel`、`ExpAsyncHasher` 文档描述

### 📝 文档
- **文档与示例**：新增 `HusImage`、`HusImagePreview` 示例与文档
  - README 更新

### 🔧 构建与工具
- **构建改进**：Android 平台不再构建 qwindowkit 库
  - 修复静态库构建的链接问题
  - 动态库名统一为 `HuskarUIBasic` 并同步调整 CI
- **开发工具**：Gallery `ThemeToken` 支持 DesignToken 重新加载后保留修改、显示非 `#` 开头颜色、预设高度

### ♻️ 其他改进
- **其他改进**：清理 0.4.0 遗留的插件命名（`DelegateUI` → `HuskarUI`）；规范代码格式

### **Full Changelog**: https://github.com/mengps/HuskarUI/compare/v0.4.1-beta...v0.4.2-beta
