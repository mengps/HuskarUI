# v0.5.3-beta (2025-12-21)

## What's Changed

### ⚠️ 不兼容变更
- 未发现不兼容变更。

### ✨ 新功能
- **新增组件**：`HusTreeView`（树视图）
- **新增主题**：`HusTheme` 新增 `HusTreeView` 主题对象
- **新增属性**：`HusTextArea` 新增 `textFormat`
  - `HusSwitch` 新增 `iconSize`、`textFont`、`colorText`，并支持在开关中显示文本
  - `HusDivider` 新增 `lineWidth`、`dashPattern`
  - `HusIconButton` 新增 `textFont`
  - `HusTableView` 新增 `verScrollBar`、`horScrollBar` 别名
- **新增 API**：新增低版本 `QtTreeModel` 兼容实现（`TreeModel`），扩展 `HusTreeView` 的 Qt 版本支持
- **组件增强**：`HusTableView` 使用 `Set` 代替 `Map` 存储选中键，提升性能
  - `HusMultiSelect` / `HusSelect` 统一 `placeholderText` 的处理
  - `HusCheckBox` 优化选中动画逻辑
  - `HusCard` 绑定 `animationEnabled`
  - `HusText` / `HusIconText` 补充禁用态样式

### 🐛 Bug 修复
- **行为修复**：`HusColorPickerPanel` 删除 RGB 值中多余的 `%` 符号
  - `HusIconButton` 修复仅图标时高度未对齐
  - `HusMenu` 修复 Qt 6.9+ 修改数组触发 `modelChanged` 的问题
  - `HusDateTimePicker` 补充返回值类型注解
  - Gallery 修复无效果时的重复加载

### 📝 文档
- **文档与示例**：新增 `HusTreeView` 示例与文档，补充 `HusTableView` 文档缺失

### 🔧 构建与工具
- **构建改进**：修复 macOS 工作流未上传构建包的问题

### ♻️ 其他改进
- **其他改进**：C++ 源文件包含语句补充模块名，统一代码风格

### **Full Changelog**: https://github.com/mengps/HuskarUI/compare/v0.5.2-beta...v0.5.3-beta
