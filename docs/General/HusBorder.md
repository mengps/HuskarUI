# HusBorder 边框


提供统一的边框类型。

* **模块 { HuskarUI.Basic }**

* **继承自 { QQuickPen(即Rectangle.border) }**


<br/>

### 支持的代理：

- 无


<br/>

### 支持的属性：

属性名 | 类型 | 默认值 | 描述
------ | --- | :---: | ---
border.width | real | 1 | 边框宽度(参见 Rectangle.border.width)
border.color | color | 'black' | 边框颜色(参见 Rectangle.border.color)
border.pixelAligned | bool | true | 边框像素对齐(参见 Rectangle.border.pixelAligned)
border.style | enum | Qt.SolidLine | 边框线样式(来自 Qt.*), 仅对 [HusRectangle](./HusRectangle.md) 生效

<br/>
